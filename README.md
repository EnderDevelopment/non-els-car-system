# Non-ELS Car System

Spawn non-ELS cars in FiveM with custom liveries and extras.

## Features

- Spawn non-ELS cars with custom liveries
- Configure vehicle extras (e.g., sirens, spotlights)

## Requirements

- FiveM server
- ESX Legacy framework
- MySQL database

## Installation

1. Download the script
2. Place the script in your `resources` folder
3. Add `start NonELSCarSystem` to your `server.cfg`
4. Import the `database.sql` file into your MySQL database

## Usage

- Use the `/spawnnonelscar` command to spawn a non-ELS car

## Configuration

Edit the `config.lua` file to customize the non-ELS cars and database settings.
